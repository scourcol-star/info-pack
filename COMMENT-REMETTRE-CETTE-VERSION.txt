POUR REMETTRE CETTE VERSION EN LIGNE
------------------------------------

Le site Netlify se publie depuis GitHub : il faut donc remettre les
fichiers dans le depot. Les .txt ci-dessus servent a lire et verifier ;
pour le televersement, ce sont les vrais fichiers qu'il faut, avec leur
nom et leur extension d'origine :

    index-html-08-09.txt   ->  index.html                     (racine)
    app-js-08-09.txt       ->  app.js                         (racine)
    proxy-js-08-09.txt     ->  netlify/functions/proxy.js

Trois fichiers, rien d'autre. Une fois pousses sur la branche main,
Netlify republie tout seul en une minute environ.
